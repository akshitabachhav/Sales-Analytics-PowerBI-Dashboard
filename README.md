# 📊 Mobile Sales Analytics Dashboard

## 📌 Project Overview

The **Mobile Sales Analytics Dashboard** is an interactive data visualization project developed using Microsoft Power BI to explore and present mobile sales data.

The dashboard was created using a pre-cleaned dataset and focuses on transforming sales data into meaningful visual representations to support sales performance analysis and business understanding.

This project provided practical experience in building interactive dashboards, working with Power BI features, and presenting data in a structured and understandable format.

## 🎯 Project Objectives

- Analyze mobile sales data through interactive visualizations.
- Present sales information in an easy-to-understand format.
- Explore sales performance and business trends.
- Develop an interactive dashboard using Power BI.
- Apply data modeling and visualization concepts.

## 📂 Dataset

- **Dataset Type:** Mobile Sales Data
- **Data Status:** Pre-cleaned dataset
- **Usage:** Used as the source for developing the Power BI dashboard.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Power BI | Dashboard development and visualization |
| Power Query | Data preparation and transformation |
| DAX | Calculations and analytical measures |
| Data Modeling | Organizing data for analysis |

## ⚙️ Project Workflow

1. **Dataset Selection:** Used an available pre-cleaned mobile sales dataset.
2. **Data Preparation:** Worked with the dataset in Power BI.
3. **Data Modeling:** Applied data modeling concepts.
4. **DAX:** Used DAX for analytical calculations.
5. **Dashboard Development:** Created an interactive dashboard with Power BI.
6. **Visualization:** Presented sales information through visual elements.

## 📈 Dashboard Features

- Interactive sales analytics dashboard.
- Visual representation of mobile sales data.
- Data analysis using Power BI.
- DAX-based analytical calculations.
- Power BI data modeling.
